# physics-project-

In our project, we simulated a damped-driven pendulum, where both a time-varying external force and a drag force (dependent on velocity) act on the pendulum. This results in a second-order differential equation, which we evaluated through two different methods, the Euler-Cromer method (the one we used for the drag force lab), and the Runge-Kutta 4 order method (a different, more accurate method). 

The user can also change many physical properties of the pendulum, such as mass, length, radius, type (rod or simple), amplitude and frequency of the driving force, starting angle, and the air resistance coefficient. To alter these properties, there are menus for which you can change properties of each of the two pendulums. An additional feature that we included was a second pendulum, which can be used to be compared to the first one, or disabled if you only want to focus on one pendulum.
